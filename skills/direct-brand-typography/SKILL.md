# Direct Brand Typography

Turn brand evidence into a small, usable design system.

## Workflow

1. Read `references/typography-direction.md`.
2. Inspect official logos, existing campaigns, website, product category, audience, and approved reference designs.
3. Separate observed brand evidence from proposed campaign interpretation.
4. Define three to five brand attributes and translate them into typography, palette, spacing, image treatment, and decoration rules.
5. Prefer the exact approved brand font. If unavailable, document an available substitute based on letterform, proportions, contrast, width, and tone.
6. Assign one role to each family: display/headline or functional/body. Use no more than two families unless the brand system requires more.
7. Build a Figma-ready hierarchy with font family, weight, size range, line height, tracking, case, maximum lines, alignment, and contrast requirements.
8. Test the longest approved headline and smallest target canvas before approving the system.
9. Keep legal, price, CTA, and performance copy readable even when the campaign uses expressive display typography.

## Output

Return a compact brand-direction record containing evidence, attributes, font choices and fallbacks, type roles, hierarchy, palette, spacing rhythm, graphic motifs, image direction, and uncertain decisions requiring approval.
